Prop Pass Simulator

Runs thousands of simulated evaluation attempts with your strategy's numbers under the account's rules: trailing max loss, daily loss limit, best-day consistency and minimum days. It shows how often you pass, at what size, and how long it takes.

Monte Carlo

Account rules

Comparing every firm preset with the same trades. Each firm's target, max loss, best-day rule, min days and contract limit come from its preset. Drawdown type, daily loss limit, give-up sessions and cost per attempt below apply to all firms.

Daily loss limit 0 = off. Best-day rule 0 = off. Presets approximate published rules; check your firm's current rules before relying on them.

Instrument & costs

Contract, point value and fees here are for Single strategy. In Portfolio, each file sets its own contract and fees. Slippage applies to every trade.

How to export from TradingView
  1. Add your strategy to a chart of each ticker you trade.
  2. Open Strategy Tester → List of trades.
  3. Use the export button to download the CSV. Repeat for each ticker.
  4. Add all the files here. Check each file's contract; it is guessed from the file name.
  5. If your backtest already includes commission and slippage, set fees and slippage to 0.

Simulation

Whole weeks replays real Monday–Friday stretches in order, including days with no trade, so “Days with a setup” is not used.

The risky view adds contracts one at a time to your top performer on top of the best allocation, ignoring its “Max”, to see how far median days drop and what it costs in fail rate.

Speed view finds the allocation with the fewest median days among those whose pass rate is within this many points of the best.

With few combinations, Portfolio tests every one between each file's Min and Max. With many files it runs a step-by-step search instead (add or remove one contract at a time, keep what helps), so there is no limit on files. The best ones are then re-run at full precision.

Running the first simulation…

Each attempt replays random trading sessions drawn from your strategy's results. With several trade files, trades from every ticker on the same date land in the same session, so days where several tickers win or lose together are kept. Drawdown is checked on closed trades only, so open-trade swings that a firm counts intraday are not modeled. Past results do not guarantee future results.
